# BUG-01: «Нийт ном» тоолуур хүснэгтэд буй номын тооноос үргэлж 1-ээр илүү

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11 (Git Bash), Node.js v18.19.0, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Хуудсыг нээгээд хүснэгтийн мөрийг тоол → 3 ном.
2. Хүснэгтийн доорх «Нийт ном» мөрийг хар.
3. (API) Терминалд: `curl -i localhost:3000/api/books` болон `curl -i localhost:3000/api/stats` — номын тоо болон `total`-ийг харьцуул.

**Хүлээгдэж байсан:** «„Нийт ном“ тоолуур хүснэгтэд буй номын тоотой тэнцүү.»

**Бодит үр дүн:** 3 ном байхад «Нийт ном: 4» гэж харагдана. Ном нэмэх, устгахад ч үргэлж +1 зөрүүтэй (2 ном → 3, 0 ном → 1). API: `/api/books` 7 ном буцаахад `/api/stats` → `{"total":8}`.

**Ноцтой байдал:** Major — статистик үргэлж буруу, серверийн түвшний алдаа тул бүх клиентэд нөлөөлнө.
