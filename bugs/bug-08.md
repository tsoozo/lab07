# BUG-08: API: буруу JSON биетэй POST /api/books хүсэлтэд 400 биш 200 OK буцаана

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11 (Git Bash), Node.js v18.19.0, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Терминалд: `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'`
2. Хариуны статусын мөр болон биеийг хар.

**Хүлээгдэж байсан:** «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»

**Бодит үр дүн:** `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. Клиент амжилттай болсон гэж ойлгоно, гэтэл ном нэмэгдээгүй.

**Ноцтой байдал:** Major — API алдааг нууж, клиент талын алдаа илрэхгүй.
