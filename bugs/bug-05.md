# BUG-05: «Устгах» товч улаан биш, ногоон өнгөтэй

**Орчин:** Уншлагын жагсаалт v2.0, Google Chrome, Windows 11 (Git Bash), Node.js v18.19.0, 2026-10-21

**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Хуудсыг нээгээд хүснэгтийн «Устгах» товчнуудын өнгийг хар.

**Хүлээгдэж байсан:** «Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй.»

**Бодит үр дүн:** Бүх «Устгах» товч ногоон өнгөтэй — ногоон нь ихэвчлэн «зөвшөөрөх/аюулгүй» гэсэн утгатай.

**Ноцтой байдал:** Cosmetic — гэхдээ санамсаргүй устгалд хүргэж болзошгүй UX асуудал.
